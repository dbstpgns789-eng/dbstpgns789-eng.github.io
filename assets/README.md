# 프로젝트 이미지·폰트 출처

포트폴리오에 실제 사용한 이미지는 2026-11-04 사용자가 전체 승인했다. AI 생성 시안의 가상 교통 관제 장면과 잘못된 이메일은 구현에 사용하지 않았다.

| 파일 | 출처·설명 |
|---|---|
| `plates/maldong-image.png` | SUMTECH 2026 말똥 팀 발표자료의 실제 앱 미리 보기 화면. 기존 포트폴리오 `assets/preview.png`에서 복사했다. |
| `plates/piecepool-image.png` | 2026-11-02 확인한 공개 제품 소개 `https://piecepool.pages.dev/`의 화면. 사용자 기록이나 사용 실적을 뜻하지 않는다. |
| `plates/omniguard-image.png` | 사용자가 제공한 OmniGuard 25쪽 발표자료 `슬라이드 데모.pptx`의 `ppt/media/image3.png`. A04_carpet 433초 영상 평가 화면. 실제 설비 미연동. |
| `piecepool-app.png` | 사용자가 제공한 2026-10-19 PiecePool 사업계획서의 `word/media/image6.png`. 실제 앱과 설명을 함께 담은 원본이다. 웹 상세에는 전체를, PDF에는 상단 앱 화면을 표시한다. |

복사 전 원본과 비교 검토용 이미지는 로컬 작업 폴더에 보관한다. 공개 사이트에는 위 네 이미지와 사용하는 폰트만 포함한다.

이미지의 시각 내용을 재생성하거나 성과 수치를 추가하지 않았다. plate 세 파일에는 원본 출처를 PNG 메타데이터로 기록했다. 실제 참조 파일의 해시는 `provenance.json`에 보관한다.

폰트는 Inter Variable, Pretendard Variable을 자체 호스팅하며 각 라이선스 파일을 `fonts/`에 보관한다.
