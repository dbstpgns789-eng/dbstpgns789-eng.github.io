01

About

논문 PDF를 카드뉴스로 바꾸는 서비스, 흩어진 학습 자료를 다시 찾는 시간을 줄이는 에이전트, 전세대출 약관을 대신 읽어 주는 추천 시스템. 지금까지 만든 것들의 공통점은 사람이 쓰는 시간을 줄이는 도구라는 점입니다.

LLM을 제품에 넣을 때 가장 어려운 부분은 모델을 고르는 일이 아니라 출력이 근거에 맞는지 확인하는 일이라고 생각합니다. 그래서 생성 결과를 원문과 대조해 검증하는 구조를 설계하는 데 시간을 많이 씁니다.

지금은 한국생산기술연구원에서 국가근로장학생으로 연구 과제를 수행하고 있습니다. 다음으로는 API 호출을 넘어 모델 학습과 파인튜닝을 직접 다루는 경험을 쌓으려 합니다.
